- [Grid](../widgets/grid.md) and [track sizing](../concepts/tracks.md)
- [Constraint behavior](../concepts/constraints.md)
- [Adaptive layout](../concepts/adaptive-layout.md)
- [Resizable panes](../widgets/split-view.md) and [pane concepts](../concepts/panes.md)
- [Workspace](../concepts/workspace.md)
- [Desktop shell](../widgets/desktop-shell.md)
- [Dock layout](../widgets/dock-layout.md)

The runnable [Showcase](../../examples/showcase) demonstrates these layout primitives alongside the FFrame controls in an application hosted by `fframe` and styled by `fframe_wpf`.
